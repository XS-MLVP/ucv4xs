# MainBTB 满组连续学习的分支保留与替换顺序

MainBTB 学到新分支时，不仅要保存其目标，还要让下一份学习知道它刚刚建立。
已有 MBTB-017 从空组建立两个不同 tag 的分支；满组时连续学习的保护、方向初态
和后续替换顺序尚需独立验证。这些是同一要求的细化，不按物理 bank 或 set 新增功能点。

当前专项已补齐不同分支位置关系的完整消费者和双向年龄隔离证据：四个新程序
通过，原四个相同位置程序仍因方向串改普通 FAIL。该要求整体仍未通过。

## 功能要求

满组原有 A、B 两个居民，连续到来的 C、D 都是不同 tag 的新条件分支。
第一次分配替换 A，第二次应替换 B，不能立即覆盖 C。C、D 各自从弱 taken
初态开始，不能继承旧居民的方向，也不能因另一 tag 的反馈改变计数。
再学习 E 时应淘汰 C，保留较新的 D。交换 C、D 的输入顺序后，逻辑规则不变。

跨页邻接的另一个窗口是独立上下文。它的分支内容和替换年龄都不能受上述学习影响。
先让两个上下文具有不同的受害者，再用邻居自己的新分支触发替换，检验年龄隔离。

## 场景与独立预期

| 阶段 | 目标窗口 | 独立邻接窗口 | 观察目的 |
| --- | --- | --- | --- |
| 准备 | 两个旧条件分支，方向计数分别为 0、3 | 条件分支计数 3，另一条为带调用属性的直接分支 | 与新分支计数 2 有区分度；两个上下文的受害者不同 |
| 捕获 | 同时在途的两份真实冷预测 C、D | 保留原内容 | 来源独立、完整 metadata 不改写 |
| 连续学习 | 两份正常误预测反馈 | 无反馈 | 比较真实载荷及相邻接纳；串行模式为对照 |
| 新鲜消费 | C、D 全字段正确，旧 A、B 均 miss | 两个旧居民完整保持 | 两个命中不能代替目标、类型、位置和方向检查 |
| 后续竞争 | E 替换较早的新居民 | 新邻居替换其自己的旧受害者 | 通过实际幸存者证明两份年龄及其隔离 |

程序使用页边界两侧的代表窗口，不枚举物理位置。独立语义程序从正常分配、方向学习
和最近使用关系预先计算居民，不能拿实际 way、counter 或 SRAM 内容初始化答案。
默认周期参考模型始终检查公开输出；新程序在其上增加完整来源和消费者合同。

## 证据与失败判定

覆盖分为 reached 与 checked。只有实际来源、接纳和消费者满足义务才记 reached；
所有比较完成后才记 checked。异常直接交给 pytest，不新增或扩大 XFAIL。
主参考模型更早发现差异时保留原异常与程序上下文，不能为了继续场景而关闭比较。

原生缺行目前仍有 50 个 MainBTB 替换状态副本。它们与同一替换事件有关，不代表
50 个新功能。该程序优先弥补满组语义证据；行命中是否增长必须由实际回归决定，
不能据此删掉原生分母，也不能把新增定义当成功能通过。

## 分开检验学习归属与替换年龄

满组新分支可能与旧居民具有相同或不同的指令位置。这不是不同物理坐标，
而是学习归属的两种关系：位置相同仍不能把另一 tag 当成原分支；位置不同时，
也必须保存新分支并维护近期使用顺序。原来四个相同位置反例完整保留，不能用
后一类的成功抵消它们。

新增程序保持同一组地址、旧计数 0/3、新计数 2、双向输入顺序和串行／相邻模式，
但两个新分支位于旧居民未使用的两个位置。仍通过完整新旧消费者、第三次分配
和邻居自己的分配比较年龄。若该程序通过，只证明这类位置关系下的替换义务，
不证明相同位置串改已修复，也不将 MBTB-017 改判 PASS。

既有两组覆盖扩展为每组 72 项义务：两种位置关系、两种模式、两种顺序、九项
规则。原 36 个 bin 的名称和含义保持，新 36 个 bin 单独命名。覆盖 schema 更新，
新分母及原反例的未命中项都保留，不新增覆盖组来掩盖失败。实际结果另行核验。

年龄隔离的观察顺序必须有区分力：两份新学习后先让邻居发生自己的容量竞争，
再让其幸存旧分支接纳一次正常 taken 反馈，最后才触发目标窗口的第三次分配。
第一次竞争可以发现目标学习错误改变邻居年龄；后续合格邻居访问可以发现反向
串扰。不能先更新目标年龄再观察邻居，因为后一次写出的相同值可能掩盖先前
的错误。首次试跑的通过记录不据此关闭年龄隔离义务；全量实验已中止并保留原因。

## 不同位置关系的实际补证

修正观察顺序后的四个程序全部 PASS，原四个反例仍普通 FAIL。两种关系共同
保留在 72 项义务的分母中：reached 48/72、checked 36/72。原 36 个 bin 名称
不变，其中 checked 仍为 0；新 36 个 bin 均比较通过，不为此增加新功能 ID。

实际程序先证明两条新分支各自保有完整目标、位置、类型、方向与计数 2，旧
目标均 miss，邻居内容不变。邻居随后只淘汰自己的旧居民；其幸存分支再接纳
一次正常 taken 反馈，保持计数 3。目标的第三次分配仍淘汰较早的新居民，而
不是被邻居访问改变受害者。这些结果只证明当前两路配置的声明程序，不消除
相同位置反馈的跨 tag 串改，也不证明任意调度或全部 FTQ 生命周期。

检查器在授予 checked 前要求所有声明的实际消费者存在，不能靠调用方手工
标记规则完成。每个通过程序检查 31 份已保存 metadata 的不变性，全部公开
输出仍经过默认自主周期模型。54 项纯模型与负向检查通过；其中新增 19 项
包含漏消费者、错受害者和两种位置关系覆盖混淆的拒绝。

最终模块选测为 965 项：957 PASS、8 FAIL，原 942 项判定保持；纯模型的模拟
成功样本未进入 DUT 测量。见
[实际来源与两向隔离证据](../results/mbtb-full-capacity-age-evidence-20261017-v2/event-qualification.json)。
已取消实验的[原因记录](../results/production-mbtb-full-capacity-age-20261017-v1/cancellation-analysis.json)
保留，但不作为全量结果或年龄隔离完成证据。

最终完整复验 19452 项：19417 PASS、32 普通 FAIL、3 严格 XFAIL，64 进程 owner
601.58 秒，pytest 572.32 秒。原 19429 项判定、343 点状态均保持；新增 23 项
全部 PASS。除本项两个覆盖组的显式 schema 扩展外，其余 385 组比例保持；
十个 DUT 原生键和命中集合不变。见

## 首次实际结果

四个 DUT 场景均在首个新分支的新鲜消费处普通 FAIL：方向计数应为 2，实际为 1，
预测方向因此从 taken 变为 not taken。两种输入顺序、相邻反馈和串行对照均复现；
这不是只有流水重叠才出现的问题。35 项独立模型与故障注入检查全部通过。

实际监视器证明两份反馈都使用原冷来源，rawHit 均为 0，实际方向均为 taken。
旧居民留下的同位置无效 metadata 计数为 0；第二次反馈错误地将其递增为 1，
覆盖首个新分支刚初始化的计数 2。RTL 的
[方向更新资格](../XiangShan/src/main/scala/xiangshan/frontend/bpu/mbtb/MainBtbAlignBank.scala:259)
只匹配条件反馈与位置，未要求 rawHit。该表现与已有 MBTB-027 的跨 tag 学习缺陷一致，
不能按四个参数组合记成四个独立 RTL 问题。

四个场景都完成了满组准备、真实重叠来源和实际反馈节奏三个义务；共 36 项参数化
义务中 reached 为 12，checked 为 0。主模型阻断后续比较，因此当前没有硬件证据证明
第三次替换及邻居年龄正确。原空组测试不删除；MBTB-017 的新合同不能继承它的 PASS。
未修改 RTL，未新增 XFAIL，未放宽参考模型。

完整 MainBTB 选测为 942 项：934 PASS、8 FAIL，原 903 项判定逐一保持。
新增 35 项纯检查全部 PASS，四项真实 DUT 程序普通 FAIL；纯检查的模拟覆盖
不进入 DUT 测量，模块汇总 checked 仍为 0。可复查的
[实际来源与首错证据](../results/mbtb-full-capacity-evidence-20261017-v2/event-qualification.json)
保留两种顺序的冷来源、相邻间隔 2 half-ticks、串行间隔 10 half-ticks 和完整反馈。
这些间隔是监视器测得的事实，不是 testcase 等待指令。

完整生产复验为 19429 项：19394 PASS、32 普通 FAIL、3 严格 XFAIL，64 进程
owner 682.27 秒。原 19390 项判定逐一保持；MBTB-017 由 PASS 转为 FAIL，
其余 342 项定义及节点判定映射不变。387 个功能组中 349 个全满，原 385 组
比例保持。十个 DUT 的原生 DA 键和命中集合无增无损，MainBTB 仍为 1006/1056。
完整源码冻结、产物和分母核验见
[诊断资格](../results/production-mbtb-full-capacity-learning-20261017-v1/qualification.json)。
