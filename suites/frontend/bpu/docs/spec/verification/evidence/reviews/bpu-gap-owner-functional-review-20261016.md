# BPU 剩余缺口关联要求：恢复、退休和等待服务的身份

本阶段先定义，不新增DUT刺激。依据完整测量
`production-utage-source-ownership-20261016-v1/gap-map.json`的43个关联功能ID，
补齐其中剩余17项合同。每个零DA键与要求的关联不等于其未命中原因已闭合；
相关ID全部有合同也不等于全部功能规格或测试证据已完备。

三个切点必须保留：PHR参考接纳真实决策/恢复输入，不是所有预测决策的自主
golden；SC组件参考的ready是观察输入，不能宣称独立预测全部仲裁；提交栈
参考接纳实际推测/退休来源，不证明MainBTB任意指令发现或完整FTQ调度。
另一些TAGE/Main学习程序确实组合了自主历史与预测模型，两者不能混为一谈。

以下“完整”始终指声明范围的完整定义字段，不包括无效数据，不宣称所有
地址/历史/容量组合。现有物理覆盖分母原样保留，示例坐标不是功能名称。

### INT-034：恢复到原分支历史，不把新请求的历史当成旧检查点

- 事件：正常接纳的预测产生真实检查点，后续恢复请求引用该原始来源。
- 所有权：检查点属于接纳时的分支及历史版本，不属于恢复当拍的线上PC或最新metadata。
- 效果：恢复正确历史与待决更新，随后折叠索引及公开metadata均来自该历史版本。
- 观察：按真实推进/冲刷关联来源，独立比较全部历史单元、折叠、指针和后续公开metadata。
- 保持：流动和背压下来源均不串龄；被取消年轻路径不能继续贡献有效更新。
- 范围：reset可达偶数指针轨道及真实捕获检查点；奇数轨道与全FTQ合法性未证明，旧零bin不排除。
- 证据边界：PHR输入切点独立于实际存储状态，但不是整个预测方向的自主参考；物理指针全遍历不是独立语义要求。

### INT-035：中级否定早期taken时，恢复原分支历史并消除错误路径影响

- 事件：早期预测已推测taken，正常学习的中级结果对同一来源纠正为not-taken。
- 所有权：纠正属于原早级分支及其原历史，不能关联到后来的同PC请求。
- 效果：恢复原历史并形成正确not-taken后续状态，公开fallthrough和分支位置正确。
- 观察：真实中级纠正、推进/冲刷及原token相互对应，比较全部历史状态与随后晚级metadata。
- 保持：实际纠正当拍即使下游背压，已接纳老token仍保留，不使用更晚的无关停顿冒充并发。
- 范围：真实MainBTB/micro预测分歧、流动与背压场景；不是任意预测器组合或FTQ证明。
- 证据边界：实际纠正是输入资格，PHR参考负责其历史效果；不能反过来用PHR一致性证明方向预测本身正确。

### INT-036：晚级统计修正否定taken时，只恢复其原始路径

- 事件：真实SC达到使用资格，对同一原分支的TAGE-taken结果给出not-taken晚级纠正。
- 所有权：晚级修正及其历史属于原早级token，不能以当前PC相等作为关联。
- 效果：撤销该来源的错误taken历史，保留正确not-taken状态与公开修正窗口。
- 观察：核实SC真实资格和纠正，再按来源比较全部历史、折叠及因果对应的公开metadata。
- 保持：年轻请求不替代原来源；流动与纠正当拍背压均不能丢失原检查点。
- 范围：声明的TAGE/SC方向分歧和真实训练程序；不外推非零全历史或任意FTQ寿命。
- 证据边界：真实SC资格、PHR效果和整个SC自主权重规格是不同证据层次，原场景不自动关闭三者所有要求。

### INT-037：中级taken纠正在历史环边界仍保留分支与路径身份

- 事件：中级对历史指针处于起始边界的原分支给出真实taken纠正。

- 观察：从真实零历史来源构造边界，核实实际taken纠正、目标/位置及全部历史和折叠状态。
- 保持：不捏造指针或metadata；其他存活路径及原来源快照不被年轻请求替代。
- 范围：reset可达零边界的中级taken内层跨环，流动/背压；不是not-taken外层分支或奇数轨道证明。

### INT-042：没有有效公共历史时，不从不存在的历史学习SC权重

- 证据边界：完整记录版本和方向队列有不同合并语义；仅检查最终目标不能证明两个方向来源均已接纳。

## 定义完成的边界

最新缺口关联的43个ID现在都有逐点合同，未新增同义ID，仍不表示所有333个
硬件功能点均已逐项审查。默认物理副本未访问、局部守卫矛盾、真实输入资格
未形成、前置普通FAIL阻断及效果/消费者证据不足继续分别记录，不统称“缺case”。
下一阶段按尚未闭合的子义务设计前态和消费者，而不是重复枚举地址。
