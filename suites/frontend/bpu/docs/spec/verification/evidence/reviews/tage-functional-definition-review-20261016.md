# TAGE：按分支学习语义审查全部功能定义

本次在任何新增DUT刺激之前审查剩余32项旧ID，原023/024/026/035合同保留。
目标是统一定义层次，不把表深度、bank、槽号或固定反馈次数当作功能名称。
现有36个ID保留用于追踪，语义重叠要明确，不按物理坐标再增加ID。

## 语义与证据切点

TAGE用不同长度历史识别分支。provider是最长匹配历史的预测来源；alternate
是次长来源，没有alternate时可参考基础预测。方向计数、替换保护、选择偏好
分别有自己的所有权与更新规则，不能用“预测方向没变”同时证明三者。

依据固定源码 `tage/Tage.scala:300–658` 的选择、学习、分配及投票职责，及
`WriteBuffer.scala:153–248` 的版本合并。默认 `model/semantic.py` 从reset独立
维护条目、历史坐标、选择器、随机分配及服务义务；它消费独立UT的公开上游
metadata，不证明集成PHR或FTQ来源合法。pair/mixed/overlap/shadow模型各有更窄
的已分配/零历史/容量前提，不能用它们单独证明完整分配或任意双写仲裁。

本轮原生剩120行仍是已审查的局部优先级复制路径，不新增120个功能，也不
排除分母。已有026普通FAIL保持；下方新合同只定义要求，不把旧PASS扩大。

### TAGE-001：没有匹配分支时，交还基础预测而不制造虚假历史来源

- 事件：reset后的冷身份或没有匹配tag/位置的分支被正常查询。
- 所有权：本次PC、历史及分支位置共同确定匹配资格，不属于当前任意表项。
- 效果：不存在provider时不制造有效TAGE纠正，调用方仍能采用自己的基础预测。
- 观察：比较实际有效性、来源metadata与独立冷态期望，不把无效方向数据当真值。
- 保持：冷查询不分配条目，不修改其他分支与历史的已学状态。
- 范围：独立TAGE冷查询与基础回退；不声称无效总线上必须编码某个固定方向。
- 证据边界：旧cold用例与默认参考保留；没有专属成对事件组，不借通用满组闭合全部miss组合。

### TAGE-002：合格误预测为原分支建立可被后续查询消费的新历史来源

- 事件：匹配真实条件分支metadata的误预测反馈提出合法的新项分配需求。
- 所有权：新项属于原PC、历史和分支位置，不属于随机选择的物理槽本身。
- 效果：从有资格的更长历史候选中建立弱方向初态，随后原身份能够命中。
- 观察：独立reset随机序列和候选资格推导分配，实际学习后用fresh查询比较完整定义字段。
- 保持：受保护邻居与无资格身份不被误分配，原反馈快照不修改。
- 范围：独立UT合格分配及声明配置；不是集成FTQ调度或所有候选竞争证明。
- 证据边界：旧单分配PASS不是随机筛选全部分支、回退候选与所有替换边界的独立证明。

### TAGE-003：重复taken学习增强原provider并在上界保持，而不回绕

- 事件：原provider接纳合格taken反馈，方向从弱状态逐步强化至正边界。
- 所有权：计数属于原分支的实际provider，不属于随后被查询的其他身份。
- 效果：计数按合法来源递增并在上界保持，后续方向和完整provider仍正确。
- 观察：分别比较强化、上界前后和继续同向学习的fresh实际消费者。
- 保持：tag、位置、未参与provider及原来源metadata保持。
- 范围：taken方向计数链；替换保护、选择器边界和反向恢复不是由方向稳定自动证明。
- 证据边界：旧counter用例和默认模型保留；尚无专属分开的到达/检查组。

### TAGE-004：重复not-taken学习削弱原provider并在下界保持，而不回绕

- 事件：原provider接纳合格not-taken反馈并逐步到达负边界。
- 所有权：学习属于原分支及provider的最新合法方向版本。
- 效果：计数递减至下界后保持，不能回绕成强taken或丢失原身份。
- 观察：比较逐步变化、下界及继续同向学习后的完整fresh预测。
- 保持：邻居、tag、位置和原metadata保持，不以其他表的同方向输出代替原provider。
- 范围：not-taken方向计数链；其他状态的边界或全历史输入仍另行审查。
- 证据边界：与003是相同饱和算法的两端，保留旧ID但不将每个计数值新增为功能。

### TAGE-005：弱来源允许基础回退，强化后的来源能重新主导预测

- 事件：一个真实匹配provider从弱方向经过合格学习进入强方向。
- 所有权：是否采用provider由该原分支的置信度和对应共享选择偏好共同决定。
- 效果：弱态合法回退，强态重新采用provider，不因回退隐藏原来源学习。
- 观察：比较回退与采用两种真实消费者的来源、方向、计数和选择metadata。
- 保持：provider身份及未参与历史保持，不能用重新分配冒充同一来源强化。
- 范围：既定基础回退链；真实alternate的精确计数与全部共享选择器状态另见029。
- 证据边界：基础方向可以由UT上游提供；这不是完整基础预测器自主组合证明。

### TAGE-006：原provider提供真实额外价值时获得替换保护

- 事件：原provider与alternate或base分歧，合格反馈确认provider正确。
- 所有权：奖励属于原分支的provider与原保护快照，不属于任意当前读到的表项。
- 效果：按规定增加并饱和保护，方向学习仍独立正确。
- 观察：预先区分原保护和方向，比较实际学习后的完整provider与保护值。
- 保持：不提供额外价值的来源和邻居不能获得虚假奖励，原metadata保持。
- 范围：声明的额外价值奖励；不能照搬MicroTAGE的错误惩罚或老化算法到TAGE。
- 证据边界：原用例不自动证明保护队列满、延迟服务或同拍全局维护，需分别审查。

### TAGE-007：另一分支查询不改变原身份的匹配与已学方向

- 事件：已学习分支与另一个具有可区分tag/位置的查询交错出现。
- 所有权：命中由PC/历史派生身份和分支位置确定，不能只比较低位索引。
- 效果：不同身份不误命中，回查原分支仍消费其原provider。
- 观察：比较新旧查询的完整定义来源、tag关联和回访结果。
- 保持：查询本身不修改任何条目，原provider及其他历史保持。
- 范围：已声明非别名身份的隔离；散列相同的合法别名不被错误要求为无限容量独立存储。
- 证据边界：单个PC对照不是所有地址位、历史位或物理副本等价证明。

### TAGE-008：没有更长历史可分配时，原最长provider仍能正常学习

- 事件：最高历史provider接纳taken或not-taken方向反馈。
- 所有权：反馈属于原最长来源，没有更长表不取消它的方向学习义务。
- 效果：方向计数双向更新并保持该provider，不能误创建不存在的更长来源。
- 观察：分别比较两方向的新计数、身份和后续真实消费者。
- 保持：其他驻留分支及原metadata保持，方向更新不依赖成功分配。
- 范围：最高历史边界及正常方向反馈；不代表所有分配失败或全局维护组合。
- 证据边界：表编号是本配置边界参数，不按每个表编号复制该功能。

### TAGE-009：没有可替换候选时，失败分配不能破坏受保护分支

- 事件：原分支需要分配，但所有合格候选均有不可替换保护。
- 所有权：保护属于既有逻辑分支，新请求无权因失败而清空它们。
- 效果：新项保持未建立，所有受保护驻留身份和方向保持。
- 观察：实际失败后查询新分支与全部声明驻留分支，核对完整provider状态。
- 保持：失败不重写邻居tag、计数或保护，也不伪称发生了成功服务。
- 范围：声明的满保护候选集；不同于无反压写缓冲满行替换，不混用两种容量契约。
- 证据边界：旧满set用例不是全部候选筛选/随机竞争的独立完备证明。

### TAGE-010：持续失败触发保护维护，释放分配机会但保留方向身份

- 事件：真实合格分配连续失败，达到保护维护条件并实际完成维护。
- 所有权：失败次数属于真实分配机会，维护的是替换保护而不是分支方向条目。
- 效果：清除保护后新分支可分配；只有合法受害者被替换，其他身份与方向仍在。
- 观察：独立累计失败与维护进程，实际重新分配后查询新项和全部幸存者。
- 保持：无资格/无需分配事件不算失败，维护不抹除方向或让旧待写保护在完成后复活。
- 范围：声明的维护后重新分配链；不自动证明同拍新奖励、读冲突和维护全过程的全部组合。
- 证据边界：旧用例只在最终消费者观察恢复；维护中的旧奖励冲刷/并发学习仍需专属义务和证据。

### TAGE-011：相邻查询不同分支位置时，来源随原请求而不是最新位置返回

- 事件：同PC下已学位置与冷位置的请求相邻进入查询流水线。
- 所有权：每份响应属于原请求位置及其读取快照，而非返回当拍位置。
- 效果：provider只返给匹配位置，冷位置保持无来源，响应次序正确。
- 观察：重叠发送、按实际接纳与完成关联，比较每份完整定义预测。
- 保持：原请求及历史快照不可变，冷/热交错不修改已学条目。
- 范围：独立TAGE位置流水关联；不将固定延迟本身当作功能语义。
- 证据边界：旧位置交错和默认异步scoreboard保留；全背压/取消调度仍非本用例范围。

### TAGE-012：高置信基础预测回退不阻断原弱provider的合法学习

- 事件：弱provider与高置信base分歧，而真实反馈确认base正确。
- 所有权：反馈仍属于原provider及原基础置信类别，不因未被采用而丢失。
- 效果：回退和来源metadata一致，原provider按真实结果更新并可重新评估。
- 观察：比较回退、原计数变化、置信分类及fresh选择结果。
- 保持：原tag与未参与分支保持，不用额外分配取代已有弱来源。
- 范围：基础预测高置信回退；真实alternate和全部置信桶另行声明。
- 证据边界：base_conf只是UT输入的合法切点，不证明上游基础置信度生成算法。

### TAGE-013：一个分支的反馈可改变共享选择偏好，但不能改写另一分支计数

- 事件：两个弱provider共享同一选择偏好类别，只有其中一个接纳合格反馈。
- 所有权：选择偏好属于共享历史深度/置信类别，方向计数仍各属原分支。
- 效果：未训练分支可改变采用来源，但自身条目、方向计数和保护不被当作被训练对象。
- 观察：保留未训练弱探针，比较选择变化与探针计数/身份不变，区分偏好学习与重新分配。
- 保持：其他类别的选择偏好、原条目与来源快照保持。
- 范围：共享选择器的跨身份效应；到达两端后的保持与反向恢复尚需独立DUT证据。
- 证据边界：原cross_tag仅穿越选择阈值，不能据此证明5位选择器两端饱和或类别隔离全部边界。

### TAGE-014：不同历史深度的原provider都接纳匹配置信类别的学习

- 事件：自然分配到不同历史深度的弱provider接纳高置信基础反馈。
- 所有权：学习属于各原provider，选择偏好按该深度与置信类别归属。
- 效果：各来源按真实结果强化或翻转，弱态回退与强态采用一致。
- 观察：逐深度比较原身份、精确计数和选择结果，不只检查访问过表编号。
- 保持：已学习的其他深度驻留项及非目标偏好类别不被串写。
- 范围：当前四深度及高置信类别；低置信全部边界、任意历史和完整FTQ另审。
- 证据边界：深度覆盖是配置边界参数，原满组不代表每个选择器状态均验证。

### TAGE-015：关闭预测器抑制其使用和新学习，但不清除已学来源

- 事件：全局关闭期间发生原身份查询或原合格反馈，随后重新开启。
- 所有权：enable控制使用与接纳资格，不重新定义原分支或重置其历史条目。
- 效果：关闭时无有效纠正且不新分配，重新开启可消费先前来源并继续正常学习。
- 观察：比较同份真实反馈的关闭/开启对照及重新开启后的完整预测。
- 保持：关闭期间已学tag、方向和保护保持，不把无效原始数据当响应。
- 范围：已排定学习的静态关闭/开启；enable切换时既接纳在途义务的寿命需另行证明。
- 证据边界：静态disabled测试不能证明切换边界的取消、排空或保留策略。

### TAGE-016：非条件分支的目标纠正不能误训练条件方向来源

- 事件：同身份的直接/间接分支反馈与合法条件分支反馈分别到达。
- 所有权：方向学习资格由原真实分支类型决定，target误预测不等于条件方向误预测。
- 效果：非条件反馈既不从冷态分配也不修改已有provider；合格条件反馈仍能学习。
- 观察：分配前后分别比较类型对照与fresh provider身份、方向计数。
- 保持：被拒绝反馈不改变tag、位置、保护或其他已学分支。
- 范围：UT查询/metadata/反馈一致的类型切点；不证明集成解码或完整FTQ合法性。
- 证据边界：拒绝和可学习正对照均需保留，单独不发生写入不足以证明未错误禁用全部学习。

### TAGE-017：一份多分支反馈中的独立方向学习都被接纳

- 事件：同份真实反馈包含较早not-taken和较晚taken条件分支，中间允许空resolve槽。
- 所有权：每份学习属于各原分支和其匹配metadata，resolve位置不是预测metadata索引。
- 效果：两个provider独立向相反方向更新，再次反馈仍分别累计。
- 观察：比较完整实际接纳与两分支fresh计数、保护和provider身份。
- 保持：空槽保持无效，未参与分支和原metadata不变，不误分配额外条目。
- 范围：不同合法目标的合并反馈；同写目标碰撞与多分配需求的优先级不在此范围。
- 证据边界：两个输出都变化比两路valid更强，但不能替代所有同拍仲裁语义。

### TAGE-018：学习须找到原MainBTB分支，未匹配邻居不能遮挡合法后续分支

- 事件：合格条件反馈分别有或没有匹配原MainBTB身份，并包含较早未匹配邻居。
- 所有权：通过完整分支位置关联原metadata，不按resolve槽号直接索引来源。
- 效果：未匹配反馈不分配/更新；较晚匹配分支仍可独立学习。
- 观察：冷态与驻留态均比较拒绝/接纳对照及真实后续provider。
- 保持：未匹配身份、邻居和原快照不被另一分支的合法资格污染。
- 范围：独立UT正常metadata匹配；不证明MainBTB真实产生该metadata的所有集成条件。
- 证据边界：命中资格和位置关联是不同义务，不能仅检查一个rawHit值。

### TAGE-019：预测向量中的非首分支保持自身基础置信度和历史来源

- 事件：带空槽的多分支预测向量及不同布局相邻进入流水线。
- 所有权：provider、base置信度与位置属于各原请求的对应分支，不属于slot0或最近布局。
- 效果：只有匹配分支获得正确provider，空/冷槽不借用其他分支结果。
- 观察：重叠请求按接纳关联，逐槽比较所有有效来源与定义metadata。
- 保持：较早已学或冷分支、原布局和历史快照保持。
- 范围：四槽位置与置信关联，UT上游接口；不是全MainBTB选择算法或任意FTQ组合。
- 证据边界：slot1/2/3是稀疏映射边界参数，不独立增设三个学习功能。

### TAGE-020：同拍共享选择器的同向意见先聚合，再执行一次净步长更新

- 事件：两个不同分支在同一反馈中对同一选择偏好类别提出同向意见。
- 所有权：意见各属原分支，净步长属共享类别，各provider方向学习仍分别拥有。
- 效果：两个合格意见贡献两步而非只取首/末一个，选择更新按聚合净值饱和。
- 观察：独立补偿反馈区分零/一/二/多步，同时核实两个provider的新计数。
- 保持：无关类别、未参与身份和原快照保持，投票聚合不吞掉方向学习。
- 范围：已声明双分支同向聚合；选择器极值附近的批量饱和与反向恢复仍需独立证据。
- 证据边界：旧batch验证两步阈值差，不据此宣称两端边界或任意投票数均覆盖。

### TAGE-021：同拍相反选择意见抵消，但各分支的方向学习仍生效

- 事件：同类别两个原分支分别支持基础来源和provider，反馈同拍接纳。
- 所有权：选择意见按类别聚合，方向与保护仍属于各原provider。
- 效果：选择偏好净零保持，但两个provider分别学习自身结果。
- 观察：恢复弱探针并追加单次意见，区分真抵消与漏掉任一意见，再比较方向/保护。
- 保持：其他选择类别及未训练探针身份保持，不因净零取消全部学习。
