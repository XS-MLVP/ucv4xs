# 并发学习不能改变在途查询的原记录

UTAGE-006已有不同请求的重叠返回检查，还需要覆盖另一项义务：查询已经取得
A的读取身份时，B学习复用其曾占用的保留位置，返回仍必须属于A，不能混入B。
这是逻辑记录的生命周期要求，不是某个bank、索引或槽号功能点。

该缺口来自集成老化程序的真实反例：注册命中选择仍指向原位置，返回payload
却已属于另一记录。相关路径此前有原生行命中，因此原生覆盖不能证明这个
并发组合正确。原生缺口账本中的保留、退出与查询归属要求仍保留；本用例不
因走到复用路径就领取这些未命中行或整个生命周期要求的通过信用。

## 正常程序与独立期望

短历史表内建立两个同位置、不同历史的记录。A正常分配为不跳、计数3；B分配
为跳、计数4，再用每次新查询对应的真实反馈强化至7。A的一份版本与B的七份
版本形成八份最近学习历史。下一次B反馈仍来自新的B查询，恰好使最老A版本
退出保留集合。这是配置容量的前态，不是穷举地址，也不是等待若干周期。

在该学习的注册处理期间连续发出原查询：读索引来自A，匹配上下文来自B。
A的tag与B不同，故原查询应miss；若误取B的payload，就会错误命中并预测跳。
driver和monitor必须证明查询实际先接纳，A到B的复用确实发生在其返回窗口内，
而不是用结束后看到B代替并发证据。之后fresh查询A、B及冷邻居，并检查原始
metadata不变。反馈只能消费各自新来源一次。

期望来自预先声明的逻辑记录、正常分配和饱和更新，不从actual命中、槽位或
返回数据决定。常驻自主周期参考同时运行。只读memory-direct仅用于确认实际
前态、复用和时序，不给参考模型灌入表内容。失败正常抛异常，不新增XFAIL。

## 范围与完成条件

这是短表UT的独立读取／匹配祖先切点；FastTrain是公开指导输入，并非后端
提交真值，不外推完整FTQ合法性。集成反例仍由原BPU程序证明。长表、全表
持久性和其他并发组合保持原有义务，不由一个短表用例代替。

reached只记录实际已建立的身份、唯一反馈、重叠复用和返回；checked须等完整
查询比较、fresh消费者和快照不可变性全部通过。纯模型与负向注入只验证检查
器，不产生DUT覆盖信用。旧006的PASS不自动证明本次新增子要求。
