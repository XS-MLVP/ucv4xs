# 循环迭代上下文的预测身份与恢复

循环迭代历史 IMLI 表示当前预测流连续预测 taken 向后条件分支的次数。
它属于具体预测版本，不是条件方向历史 GHR，也不能从当前寄存器或收到的
metadata 值反推参考状态。旧预测恢复时，年轻执行即使已经饱和，也不能
把旧预测的原迭代次数改成当前值。

## 语义要求

新预测保存独立模型的当前循环上下文。只有 taken 向后条件分支将其原
上下文加一，最大保持255；向前条件、不跳条件和向后直接跳都清零。
这里后向关系遵循当前设计的低20位半字地址合同，不把它扩大为完整虚拟
地址大小比较。暂停且没有恢复或修正时保持。

后台恢复使用真实原预测的快照。流水线内后级修正同样使用修正者自己的
快照，而不是较年轻预测已推进的游标。恢复优先于末级修正、次级修正和
早期推进；这个年龄关系由已有自主流水线模型产生，迭代模型不从实际
override 信号决定参考分支。

## 成批用例

五个实际 DUT 程序共用正常公开训练建立的向后条件循环。各自保留不同
真实来源，让年轻预测自然饱和，再比较下列恢复。

| 原来源和结果 | 恢复的迭代上下文 |
| --- | --- |
| 非零且未饱和，taken 向后条件 | 原计数加一，而不是年轻游标的255 |
| 同类旧来源，taken 向前条件 | 0 |
| 同类旧来源，条件不跳 | 0 |
| 同类旧来源，taken 向后直接跳 | 0 |
| 原来源已经饱和，taken 向后条件 | 255，不回绕 |

每个程序比较有效流水级携带的原计数、实际恢复输入、当拍新查找和后续
注册状态，再取得新预测的两个公开 metadata 快照。保存的原 metadata
必须保持不变。等待以独立模型进展、实际接纳和状态保持为终点，超时只是
诊断预算，不用固定周期暂停制造预期。

第六个程序正常学习弱负 TAGE provider，并在禁用 TAGE 时使 Main base
转为 taken。重新启用后的真实 S2 选择原始负方向，S3 采用相反的 base，
必须发生末级方向修正。核对该原来源的迭代快照、修正当拍新查找、下一拍
注册状态和恰好由修正发出的新预测身份，不用另一次后台恢复替代消费者。

## 覆盖与证明范围

新增 BPU-INT-099 独立登记这项语义，不改变原 INT-043 和 INT-094 明确
排除 IMLI 的证据范围。五个后台恢复程序分别记录 reached 与 checked 八项义务；
纯模型和故障注入检查不贡献 DUT 功能或原生行覆盖。末级程序另有五项配对
义务，只有出现实际末级修正及准确的新消费者才算 DUT 证明；纯模型优先
关系不能代替它。

此项来自历史状态归属的模型缺口，不把 CommonHR 每个未命中 DA 键都解释
成一种新功能。已归因的局部互斥键仍在原始分母中保留。任意延迟 GHR/BW
查找、SC 学习索引和完整 FTQ 来源存活资格仍是不同的开放组合合同。

## 当前验证结果

六个真实DUT程序及59项纯检查全部通过，45项reached和45项checked义务
闭合，12个新组全满。专项127 PASS；一次64进程完整诊断20100项为
20065 PASS／32普通FAIL／3严格XFAIL，原20035节点及判定保持，所有专项
实际恢复和消费者数值在完整轮复现。435组／397满，原423组比例不变。

十DUT原生DA键和命中集合保持，没有本批行增长；IMLI补证不关闭原094
两项失败或其他未验证范围。见[完整诊断](../results/production-loop-iteration-20261017-v1/README.md)
