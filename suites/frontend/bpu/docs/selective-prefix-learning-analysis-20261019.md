# 正确NT前缀免写，不取消较晚分支的独立学习

## 补齐什么功能

先写入[前缀语义契约](selective-prefix-learning-contract.json)，再扩展已有 INT-086。没有新增功能编号，也没有用 bank、way 或缓存深度作为功能定义。

此前 8 个选择性学习程序只完整证明首分支的旧 NT 结果仍有效、后继缺席或免写。此次补充较晚分支：首分支明确为正确 NT 且在下界，不需要写入；较晚分支的未饱和旧原件仍应独立教导当前结果。缺少前缀结果的部分反馈与明确包含已执行 NT 前缀的反馈分别测试，不把两者当成同一种执行证明。

| 合格的旧来源 | 当前累计 | 本次仍应提出 | 不参与学习的另一分支 |
| --- | ---: | ---: | --- |
| 首分支原计数2、正确NT（原8程序） | 0 | 1，服务结果仍为0 | 后继缺席或原值/当前值均为7的正确T |
| 较晚分支原计数5、正确T（新8程序） | 7 | 6，服务结果仍为7 | 前缀缺席或原值/当前值均为0的正确NT |

较晚分支随后以完整 NT 前缀及实际错误的 NT 后继从7减到6，再由新来源的 NT前缀/T后继恢复7。这个反向学习改变的是置信计数，不声称一次反馈便已翻转预测方向。

## 实现和检查

复用上一轮的模型、case、env、checker、bundle和monitor，不新建一个同功能框架。程序声明实际前后分支、原计数、预期提案与反向结果；检查器仍独立核对每份真实原件、实际接纳、全部提案、读竞争下旧消费者、恰好一次完整服务和新消费者。反向与恢复检查完整分支位置、目标、类型、taken、错误标记和原来源归属。

两/四个真实来路分别对应有余量与占满保留容量；末份旧原件分别在仍待写、已经服务后到达。每种边界均检查其他来路、未参与分支和全部原metadata保持。8个旧程序的pytest身份不变，新增8个后继程序；覆盖率分母从64项扩展至128项，不把旧64项历史结果当作新128项通过。

纯模型初验发现旧测试的服务计账只数第一路：8个新程序因此失败，另外188项通过。改成统计全部独立服务后196项通过；没有修改核心参考策略或RTL。负例另外确保反向后继省掉已声明的NT前缀时明确报错、不授予checked。

## 后续不重复什么

选择性学习的上述首/后分支组合已有完整闭环，不继续换坐标重复它们。TAGE剩余87条开放行仍需按旧身份迁移、独立义务竞争等行为检查既有证据；120个既有局部守卫矛盾行保留分母，不能凭未命中虚构功能。SC剩余336行的现有归因都是局部守卫约束，不适合靠枚举刷行。

进一步逐条审查发现，大块来路经验缺口的主体此前不够明确：UTAGE的1,843行与BPU的2,193行，共4,036行，全部对应短历史经验的`usefulEntries`保护更新，而非方向计数或数据持久写回。原始Chisel明确分开`newMicroTageEntry.takenCtr`和`newUseful`，父模块实例也区分短/长历史表。当前缺口报告已把这些行关联到“原经验保护的建立、原有效纠错奖励/原错误惩罚、边界保持”，不再用学习持久性失败概括它们。见`results/current/protection-frontier-review.json`；这只是源码语义归因修正，不新增测试信用，不证明其余物理副本等价，也不消除已有持久性FAIL。

下一步优先核对既有短/长保护九类事件、跨分支保护竞争及真实旧来源资格，判断是否缺少不同分支PC下的保护归属组合；同时审查更大的早期方向缺口。没有完成这一步前，不新增按保护单元索引枚举的case。
