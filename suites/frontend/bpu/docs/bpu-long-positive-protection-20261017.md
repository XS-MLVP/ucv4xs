# 原长历史跳转记录的保护边界

INT-066还需要独立证明T长记录的保护边界。原生缺口中仍有长表的保护保持／
变化职责；T短表通过不能覆盖这些来源义务。长表自然分配保护为2，短表为1，
而且最长provider错误时没有更长候选，不能把短表的分配后继直接套过来。

## 原记录必须先于新输入声明

用正常来源和独立S3指导建立T长记录，并完成其分配效果的实际比较。后续
输入前从独立种子池声明一份原长身份，保留PC、历史、tag、位置与原owner。
后续窗口只能消费这份身份，不能把任意长表T命中当作原记录，也不能从实际
命中、方向或保护值重新播种期望。

正确／错误以独立S3指导为准，不宣称FastTrain是后端提交真值。短表同时
具有记录时，仍由独立最高provider选择决定原来源；不能关闭检查去强行选长表。

## 必须分别证明的事件

| 人能理解的事件 | 必要前态和效果 | 闭合要求 |
| --- | --- | --- |
| 一致T指导只增强方向 | 原分配方向4、保护2，正常增强至7，保护仍2 | 不把一致指导算纠正奖励 |
| 正确T纠正到顶后继续有效 | 原T与NT base分歧，S3仍T，保护2→3→3 | 每份原指导独立，之后同一原长记录新消费者 |
| 到顶后发生错误 | 原T指导错误，保护3→2、方向按真实错误变化 | 原身份保留，其他历史和快照不被改写 |
| 失去全部保护后仍可恢复 | 原保护2→1→0→0，再正确T纠正恢复1 | 方向7→6→5→4后仍T，恢复指导属于原T记录 |
| 最长provider错误没有更长候选 | 原长记录仍更新并失去保护，不向短表反向分配 | 本次真实失败只记一次，实际计数在下一比较边界确认 |
| 短表可用也不能反向分配 | 先用短记录自己的错误指导使保护1→0；原长记录仍为方向7、保护2 | 三次原长错误的学习读态中，短表保护都为0，仍无反向分配 |
| 未参与的短记录保留身份 | 原长记录经历保护2→1→0→0后，短记录仍是原tag、位置和方向6、保护0 | 新的短记录消费者先验证保留状态；它自己的后续正确学习不算长记录恢复 |
| 方向恢复不等于重新获得保护 | 原长T记录继续错误，方向4→3成为NT；之后NT错误使方向3→4恢复T，保护两次都保持0 | 五次原长错误各自只计一次无更长候选；新T方向必须由下一实际消费者验证 |
| 恢复后的T正确纠正才重新受保护 | 新T方向仍与NT base分歧，真实S3指导T，方向4→5、保护0→1 | 不能把先前NT错误重命名为奖励，也不能用其他长记录冒充原身份 |

失败次数是合格学习机会的计数，不是经过多少周期。完整来源程序中的其他
合格失败也必须由reset派生的独立账本累计；不能从实际low counter初始化，
也不能只看目标窗口而漏掉准备事件。无资格或成功分配不得冒充失败。

## 驱动与比较

所有恢复使用正常拥有且仍在保留范围内的新来源。独占driver负责联合恢复
和预测流，monitor完成完整比较后返回原生接纳事件关窗；原S2／S3与学习仍
必须完成。case只描述语义操作，不暴露边沿、经验等待、引脚写入或asyncio。

学习从原来源推导，比较实际资格、没有反向分配、完整1024保护单元以及
方向和最终原长消费者。达到边界不等于可以立即checked；来源资格、实际
效果、隔离与快照不可变性全部通过才可闭合。物理副本保留，不按bank新增点。

### 长记录方向跨界的新增要求

上述三类已通过场景的原长方向最低为4，仍是T，不包含4→3→4的跨界。
第四场景沿用正常分配和独立原身份，依次证明保护释放、零保持、T变NT、
NT错误恢复T及最终合格T纠正。要求先于相应用例采用，不按物理坐标新增ID。

四个DUT场景和同源码200项兼容检查已全部PASS。原长方向依次7→6→5→4→3→4→5，
保护2→1→0→0→0→0→1；五次原长错误分别只有一次实际失败计数。短表在五次
学习读态均可用，仍无反向分配；之后新短消费者仍读到方向6、保护0。恢复
后的新T来源先读到方向4、保护0，其owner才拥有后续0→1奖励，不能由旧NT
错误冒领保护恢复。

原46项义务保留，新增22项方向跨界义务，成对68项均全满；四场景共确认15个
边界、12个一致指导和9次原长失败。缺步骤、NT错误误标奖励、错误跨界强度、
过早保护恢复、错误NT元数据和缺失／错owner／过早／错检查点消费者均被拒绝。
负向注入还必须证明破坏确实执行，不能在关窗后错过原来源采样而侥幸通过。
