# 部分服务后相反方向的迟到学习

等待服务的方向结果属于逻辑分支的最新版本。当前计数已经被后续学习改变时，
较早但预测正确的相反方向结果迟到，仍须从当前计数学习，不能重新安装原
计数，也不能一直只减较早分支、只增较晚分支。

## 缺口与来源资格

最新完整测量在集成TAGE写缓冲中仍有137个开放DA键，包括跨来源更新、
已服务身份再激活、相反方向计数及不同保留位置的生成路径。本批针对迟到
的相反方向结果与部分服务的组合，不为每个bank、保留槽或行号新增功能。

错误结果会触发表重读，不能把它标成不重读反馈来测试旧metadata路径。
本批通过正常训练保存四个真实且预测正确的来源：较早分支的强taken计数
5和饱和7，较晚分支的强not-taken计数2和饱和0。弱provider与Main base
在正常准备中保持相同方向，使选择器和useful不被额外改变。之后按既有
正常替换和重分配迁移目标分支；原来源及其完整metadata一直保持。

部分服务后，目标公开存储为A0／B5，邻历史为A1／B5。目标B和邻B的最新
待写结果均为6。迟到的旧taken结果现在与目标A0的方向相反；旧not-taken
结果则与目标B6的方向相反，但它们对各自原预测都是正确反馈，不需重读。

## 六个语义程序

| 程序 | 原来源与当前版本的学习义务 | 完整服务后的目标及邻历史 |
| --- | --- | --- |
| 旧正向来源进入下界内部 | 原A5提出6，迁移后的当前A0变1 | 目标1／6，邻1／6 |
| 原饱和正向来源进入下界内部 | 原A7虽向上饱和，当前A0仍须学习到1 | 目标1／6，邻1／6 |
| 旧负向来源降低待写正向结果 | 原B2提出1，当前待写B6变5 | 目标0／5，邻1／6 |
| 原饱和负向来源降低待写正向结果 | 原B0虽向下饱和，当前待写B6仍须学习到5 | 目标0／5，邻1／6 |
| 两份旧来源先正后负 | 原A5的taken使0到1，再由另一原A2的不跳使1回0 | 目标0／6，邻1／6 |
| 旧正向与新下界来源先后学习 | 先由原A5使0到1，再由此前捕获的A0不跳来源使1回0 | 目标0／6，邻1／6 |

独立TAGE模型已有的要求是：原提案不变但最新保留计数会变化时，也存在
学习义务。若只依据原饱和快照过滤，第二、四组将少一次学习，第六组将
漏掉返回0的结果。实际少提案、少服务或新消费者数值错误都应失败，不能
修改模型去复现RTL的资格信号。

## 比较与范围

每笔反馈有不同真实预测检查点。taken的较早分支只反馈自己；较晚分支
不跳包含正确的较早不跳前缀。第六组只反馈较早不跳是显式UT前缀切点，
不把尚未提供的较晚结果视为不跳，也不宣称整个FTQ已经完成。

四阶段分别读取目标、邻历史和被替换历史：初始阻挡、部分服务后、迟到
学习仍阻挡、最终服务后。比较原提案、完整身份、当前归属、Main基计数、
实际SDK服务的payload和次数，保留所有无关待写结果及原metadata。先正后
负的两个实际输入不可仅凭末值相同而省略。

这细化既有INT-086，不新增同义ID。137键不会因为有定义或少量命中而整体
关闭；错误反馈重读的仲裁、同拍同目的地竞争及完整FTQ存活资格另行保留。
有界公开输入与模型出现差异时保留普通FAIL，先区分接口合同与完整FTQ
可达性，不修改RTL或将差异直接扩大为架构执行错误。

证明当前计数累计与跨owner路由可以工作，差异集中在原快照饱和的准入。
当前原生行集合没有新增；缺的是这项版本组合的判据，不把它报成行增长。
见[专项完整状态](../results/direction-turnaround-compatible-20261017-v1/README.md)。
