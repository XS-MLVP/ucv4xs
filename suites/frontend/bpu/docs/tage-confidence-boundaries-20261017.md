# 积压方向学习跨越饱和边界后反向累计

较早预测保存的是当时的置信度，不是以后学习的初值。多份较早且预测正确的
结果迟到时，应共同改变当前保留版本；到达上下界后保持，不回绕。随后相反
方向的正确旧结果仍应从当前边界离开，不能恢复旧提案或丢掉已经累计的效果。

这是INT-086的三项细化要求。现有短序列只比较一两次迟到学习，没有证明完整
跨越边界、边界保持和反向往返；它们不能继承旧用例的通过结论。

## 从缺行到语义要求

最新完整测量的集成TAGE写缓冲仍有137个开放DA键，其中包括保留计数饱和
时的更新分支。实现位置是[WriteBuffer_8.sv](../rtl/bpu/WriteBuffer_8.sv)，语义
来源是[WriteBuffer.scala](../XiangShan/src/main/scala/xiangshan/frontend/bpu/WriteBuffer.scala)。
这些分支提示缺少“旧来源未饱和，但当前结果已饱和”的场景，不能据此断言
全部137行都由此造成。其他物理副本、重写和替换条件继续保留在缺口账本中。

## 逻辑程序与历史存活

部分服务后的目标存储为A0／B5，目标B和邻历史B的待写结果均为6；邻历史A
已经服务为1。正常准备分别保存多份原A5正向、原B2负向，以及原A2／B6的
正确预测。每一笔反馈使用不同的真实预测身份，不能复制metadata或重复提交
同一个checkpoint。所有原始快照、邻历史和未提供的后续分支结果均须保持。

| 程序 | 当前目标置信度的独立轨迹 | 最终目标A／B |
| --- | --- | --- |
| 旧正向学习到上界并保持 | A从0逐笔到7，再保持7 | 7／6 |
| 旧负向学习到下界并保持 | B从6逐笔到0，再保持0 | 0／0 |
| 上界保持后转向下界 | A先0到7并保持，再由另一批正确旧来源逐笔回0并保持 | 0／6 |
| 下界保持后转向上界 | B先6到0并保持，再由另一批正确旧来源逐笔到7并保持 | 0／7 |

四个原程序使用真实taken自循环读压力。两个完整往返程序再增加正常未命中、
不推进路径历史的fall-through读流版本，保留相同的学习笔数、边界保持及反向
轨迹。原taken流反例不删除：它们同时检查长来源的历史存活边界，而不是用
更短的成功程序替代尚未完成的往返。

训练折叠历史来自[PHR重建](../XiangShan/src/main/scala/xiangshan/frontend/bpu/history/phr/Phr.scala#L321)，
并非完整原历史快照。每次实际接纳都比较memory-direct的训练折叠历史与
独立语义checkpoint的原折叠值。若原存储已被覆盖，先以历史存活资格失败，
不继续为置信度学习计功，也不据此宣称架构执行缺陷或完整FTQ输入合法。

## 比较和证据边界

模型在驱动之前声明每笔原提案、当前结果及其逻辑归属。检查异步提交及实际有序接纳、
原预测资格、每次更新前的完整写回前端、最后更新后的完整结果；随后要求
真实SDK写回和四阶段目标、邻历史、被替换历史消费者均比较通过，才记checked。
只看末值无法识别中途回绕，只看模型队列清空也不能证明真实SRAM服务。

沿用xreactor驱动和monitor，测试函数只选择语义程序。观察仅使用已有
memory-direct只读端口，不使用VPI、内部写入、固定等待或bank/set遍历。
长序列使用正常学习的另一读窗口：它持续与TAGE竞争，并为MainBTB方向写回
提供服务机会。发送仍使用异步driver；driver既有admission钩子在辅助Main
队列尚有工作时暂缓新接纳，不在测试中插固定等待。实际monitor分别核对
两个半窗口每笔Main更新的ready与接纳数，原生学习提案必须保持实际输入间距。
独立模型也必须无队列丢失；不能用辅助FIFO溢出来解释或豁免消费者差异。
这是声明的有界UT合同，不证明完整FTQ的全部生命周期。前三个原饱和来源
准入差异继续保留普通FAIL，不修改RTL或放宽参考模型。实际结果另行记录。

## 专项实际结果

六个DUT程序为4 PASS／2普通FAIL。两个taken读流下的上下界保持，以及两个
fall-through下的完整往返全部通过；实际完成76项配对检查、19次SDK服务、
48个消费者、68笔Main更新接纳和46次训练历史比较。

两个taken完整往返在第14笔迟到输入处首先失去训练历史资格：原长度31的
折叠值106／3409／7504实际重建成104／3441／7512，其他较短折叠仍相同。
这是原历史存活的未闭合边界，不是已证实的TAGE算术或架构RTL缺陷。失败
程序各到达8/19、checked0/19，原反例完整保留，实际后续服务不计功。

相关117项为112 PASS／5 FAIL，原64项判定保持；最终97项纯检查全PASS且
无DUT覆盖贡献。唯一新增原生行来自既有Main替换状态副本，并经单个合法
来源的通过程序独立复现，不将其归为TAGE算术行增长。见
[专项证据](../results/confidence-boundary-compatible-20261017-v2/README.md)。
