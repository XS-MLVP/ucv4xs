# L2TLB 叶子报告：MissQueue 与 Prefetch（2026-10-24）

> **可信度复核更正（2026-10-25）**：本报告保留旧 run 的历史指标；当前归因以
> `verification-soundness-20261025.md` 为准。原 5 个 strict XFAIL 的 DUT 缺陷归因
> 已被验证侧反证推翻；“100% sampled bins”不等于功能验收或不可达证明。


## 1. 范围

本轮只验证 L2TLB 的两个小叶子，不包含 PTW/PtwCache/LLPTW/HPTW/Bitmap/MptChecker
或 L2TLB 顶层。功能点见 [functional-points-l2-leaves.md](../functional-points-l2-leaves.md)。

## 2. L2TlbMissQueue

- DUT：`L2TlbMissQueue` + 真实 `Queue40_L2TlbMQBundle`/`ram_40x47`；
  构建 `results/builds/20261024T113813508753Z-l2mq/`。
- 用例：5 PASS，覆盖入队/出队顺序、40 项满、空、flush、payload、输入位模式。
- 功能覆盖 `l2mq` 100%。
- 行 24/24 = 100%；branch 17/18；toggle 829/854 = 97.07%。

唯一 branch 缺口是 `Queue40` 时间零 initial reset 隐式 else。toggle 剩余点是
`isHptwReq`/`hptwId` 结构常量和 RAM 固定零字段（0->1 不可达）以及少量未构造输入。

## 3. L2TlbPrefetch

- DUT：`L2TlbPrefetch`；构建 `results/builds/20261024T113829798384Z-l2pf/`。
- 用例：6 PASS，覆盖下一行预取、4 槽历史抑制、index 回绕、flush/CSR changed、
  四种 s2xlate 编码、next-line 高位回绕。
- 功能覆盖 `l2pf` 100%。
- 行 39/39 = 100%；branch 22/23；toggle 657/784 = 83.80%。

未覆盖 branch 是时间零 initial reset 隐式 else。toggle 缺口为 4 个历史槽的高位
组合和部分输出地址位；测试使用互补模式覆盖了一部分，但没有伪造常量/不可达点。
功能上叶子行为由 4 槽扫描和模型逐拍检查。
