## 3. 实测语义（与直觉不同之处）

1. **没有 `lsu.resp.valid` 端口**：S2 字段只在流水时序上有效，接口默认上层总在 S2
   接收。验证按 S0→S1→S2 两拍对齐读取。
2. **`mshr_full` 不抑制普通 miss 请求**：它只阻止 speculative miss 的预留；
   `wbq_block_miss_req` 也不抑制 `miss_req.valid`，只清除 `handled`。
3. **miss 请求的 `addr` 是 64B 对齐物理地址**（不是 block 编号），宽度 48 bit。
4. **S2 vaddr 的低 6 位来自 TLB duplicate paddr**：验证时把 paddr 的页内偏移与 vaddr
   对齐，否则 miss 字段会与输入 vaddr 不一致。
5. **`resp.data` 永远是整条 128-bit bank 拼接**，不按字节 mask 截取；mask 只影响
   banked data 读的 bankMask。
