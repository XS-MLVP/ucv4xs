## 范围与假设

真实 `FrontendBridge` 闭包包含 ICacheBuffer、ICacheCtrlBuffer、InstrUncacheBuffer，
由 MemBlock 实例化。仅验证桥及缓冲接口，不代替 Frontend 取指语义、真实 L2 或 MemBlock
整体集成验收。子缓冲各自的 DUT 合同与结果独立。

`MemBlock.scala:272–325` 显示三路缓冲及非缓存 Get 固定字段，是切点和合法域的审查依据；
预期保序/稳定性来自 TL 与缓冲接口合同，不能直接复制缓冲实现作为 oracle。

## 完成条件与缺口

每条要求先确认合法域、实际接受事件与独立预期，再补正常/错误对照、硬件功能场景和覆盖。
逐 DUT 保存当前基线、参数、实际选择、种子和判定；子缓冲 PASS 不直接完成顶层三路组合。
缺少环境或合同的 smoke 保持显式失败。reset 合同未确认前不宣称在途取消已覆盖。
