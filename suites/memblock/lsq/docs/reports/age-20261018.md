## 合同、参考与观察

合同 `docs/contracts/age.md` 在测试实现前定义 AGE-RESET/ORDER/READY/REMOVE/OVERLAP/REUSE/TIMING/HOLD/POOL 九类行为。参考只有有序 ID 列表：移除 bitmap 对应项，按 enq 端口 0→1→2 追加未被同拍删除的新项；不读取或复制 RTL 年龄矩阵。

- 每个 enq 端口为零或 one-hot，非空 ID 互不相同；旧存活项不能被重复插入，除非与同拍 deq 冲突（定义为删除优先）。
- ready 是旧存活集的子集；在 DriveStable 实际输出必须选择这个集合中到达最早的项，不是最小数值 ID。
- `regOut=true` 选择当前寄存年龄，不是输出再延迟一拍。删除 ready 最老项的同拍，pre-edge 仍应选择旧最老项，不能提前按 next-age 跳到后继。
- post-edge 仅在稳定 ready 仍属于新存活集时比较。若消费者尚未撤回刚删除项的 ready，则是明确的瞬时合法域外输出，既不检查也不假称硬件有 valid 过滤；下一合法拍继续检查。比较逻辑要求非法 post 位只能来自本拍删除，不接受任意跳过。
- 入队类 checked 等待相关生命周期经实际输出选择；未证明就删除的项不计通过。删除类情形需后续重新插入/选择证明，reset 不完成旧义务。初始/活动 reset 的 checked 要等到新状态下的非平凡年龄比较，而非仅观察 reset 期输出零。
