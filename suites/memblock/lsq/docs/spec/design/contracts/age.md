# Replay AgeDetector：可参与项中的最老选择合同

本合同先于本工程年龄选择器用例实现定义。DUT 为开源 LSQ 本地 `LoadQueueReplay.scala:113-174` 对应的 **AgeDetector_36**，不是 backend/issue 中的同名类。实际规模是 **40 entries，3 个 enq 端口**，Replay 的三个 bank 各使用一个相同实例。

## 业务语义与边界

模块维护条目进入 Replay bank 的相对先后关系，并在调用者给出的 ready 集合中选择最老项。不是数值最小 ID 优先，也不意味着最老条目只要存在就阻塞其他 ready 项。同拍多入队按端口 0→1→2 建立年龄，旧存活项都比这些新项老。

移除 bitmap 可以同时删除多项；剩余项相对顺序保持。enq/deq 同拍可针对不同项；同 ID 同拍删除和入队时删除优先，该次入队不建立新生命周期。已删除的 ID 后续重新入队时是年轻的新项，不得继承旧年龄。

`regOut=true` 的实际含义是用**当前寄存年龄**做组合选择，不是再寄存一拍输出。DriveStable 的结果不能提前使用本拍 enq/deq 的 next-age；上升沿后年龄已更新，输出随新的年龄和稳定 ready 组合变化。

## 合法输入、复位和观察域

- 每个 enq 端口为 0 或 one-hot，非空端口的 ID 互不相同；不允许对仍存活且本拍不删除的 ID 重复 enq。
- deq 为任意 40 位 bitmap；删除不存活 ID 可视为幂等清理，不产生新项。同 ID enq/deq 的删除优先是定义行为，不当作非法重复分配。
- **ready 必须是当前存活项的子集**。DUT 没有公开 valid/occupancy，也不额外用对角有效位过滤 ready；对无效 ID 强行给 ready 的结果未定义，不用该输入提高覆盖或宣称无效项过滤已测。
- 本拍删除一个仍在 ready 中的旧项，DriveStable 的选择仍属于旧状态，允许消费者同拍选中并移除它。若上升沿后 ready 暂未撤回、已不属于新存活集，post-edge 输出是合法域之外的瞬时值，**不比较、不伪造过滤结果**；下一拍需恢复合法 ready，继续检查。只有在 ready 同时属于新存活集时，才比较 post-edge 结果。
- reset 中 enq/deq/ready 均为 0；复位清空所有旧生命周期。初始复位与活动中复位后按新的入队顺序检查，不能把 reset 期输出 0 当作唯一证明。
- Driver 在 FallingEdge 后驱动；被动 monitor 在 DriveStable 和 RisingEdge 采样。参考仅使用有序 ID 列表和删除/追加操作，不复制 RTL 年龄矩阵，不读取内部寄存器。

## 人类可读功能点

| ID | 行为要求 | 必需情形与判断 |
|---|---|---|
| AGE-RESET | 复位终止旧先后关系，重新入队按新顺序服务 | 初始复位、非空池复位、复位后反向重建；实际查询/选择顺序 |
| AGE-ORDER | 旧项先于新项，同拍按端口顺序而非 ID 排序 | 单路、多路、稀疏端口、ID 与端口年龄反序；逐项实际最老选择 |
| AGE-READY | 只在 ready 子集中选择最老项，没有 eligible 项时输出 0 | 空集合、单项、全体、屏蔽全局最老、多次改 ready 不改年龄 |
| AGE-REMOVE | 单/多项删除后剩余相对顺序保持，不丢弃其他项 | 最老、非最老、全部、幂等空删除；重建/复用验证删除影响 |
| AGE-OVERLAP | 同拍删除和入队建立原子的生命周期边界 | 不同 ID 并发；相同 ID 删除优先，下一次独立 enq 才能重建 |
| AGE-REUSE | 重用 ID 不继承旧年龄，反复循环仍保持真实到达顺序 | 旧最老 ID 重新入队为最年轻；全池乱序循环、多轮复用 |
| AGE-TIMING | 边沿前不得提前使用输入所描述的下一状态 | 删除当前 ready 最老项且仍有其他 ready；pre 必须选旧最老，下一合法拍选后继 |
| AGE-HOLD | 没有 enq/deq 时年龄关系不变 | 空闲；只改 ready 后再次恢复全 ready；相同结果可反复查询 |
| AGE-POOL | 完整的 40 个实际槽位都能参与年龄选择 | 高于 35 的条目、0/39 两端、全池反数值顺序插入/选择，不误用 36 entries |

覆盖 reached 只来自真实输入和状态观察，checked 要求对应选择通过比较。入队/全池关系的 checked 延后到关联条目通过实际输出被选中；在证实前被丢弃的生命周期不算通过。删除类情形还需后续重新入队/选择的证据，不能仅因 deq 位设置就算删除语义完成。reset 取消旧证明义务，不以它完成旧用例。

## 覆盖迭代

首轮只做复位、少量单路插入和基本 ready 查询，保留真实原生行覆盖。逐条审查未覆盖的年龄更新/选择路径，区分现有功能点缺少情形还是缺失整项语义；补多端口反序、全池/索引边界、删除、重用、同 ID 冲突、旧状态选择、随机 ready 和活动复位后重跑。若行覆盖已高而语义缺失，仍必须补齐功能情形，不能按矩阵 bit 组合枚举取代功能点。
